How to format your code

Write instructions line by line. Each line represents a frame in your video.

Format:

[image_filename.ext] : [duration_in_seconds]

Example:

image1.jpg : 3
photo_2.png : 1.5
intro.jpg : 5
Smart Guessing: You don't need to type the exact long name! If your image is Image136373838.jpeg, typing image1.jpeg or just image1 will automatically guess and match it.
